# Contributing

Bug reports with a **synthetic** sample are the most useful thing: copy the first few lines of your export, replace names and text with fake ones, and keep the date/time format exactly as it is. Never post real chats.

Date formats differ between phone languages. If a format is not understood, open an issue with 3-4 fake lines in that format and I will add it.

Run the tests with `npm test` (Node 18+). No dependencies are needed.
